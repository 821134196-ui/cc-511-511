# 病区陪护通行管理（本地演示）

温溪康和医院（虚构）病区陪护授权链系统：住院患者的陪护人登记 → 护士长审核发码 →
门岗核验入区/离区 → 撤销 / 转科交接。Python 标准库零依赖，SQLite 持久化，
门禁为模拟适配器，全部数据均为虚构。

## 一条命令启动

```bash
./run.sh              # 重建演示库（含转科、丢码样例）并启动
# 打开 http://localhost:8000  （可用 WARD_PORT=8012 ./run.sh 改端口）
```

启动后控制台会打印各场景演示码（也存于 `data/demo_codes.json`，仅本地演示）。

## 演示路径

首页选择身份（无需密码）：

- **门岗**（如 `HN-G1 呼吸内科·东门`）：只有扫码核验页，没有任何审批入口；
  大字显示患者代号、病区、通行结果；陪护姓名默认遮挡，可勾选临时显示；
  证件号在门岗永不显示；拒绝时原因用完整文字展示（不显示错误代码）。
- **护士 / 护士长**：按床位组织本病区视图，可登记陪护申请、审批发码、
  手机丢失/码泄露撤销、更换陪护人、封控/解封、转科、出院。
- **交接看板 `/handoff`**：转科授权链（旧病区旧码撤销 → 新病区调阅旧登记重评发码）、
  出院撤销、封控状态。
- **通行记录 `/records`**：入区/离区/拒绝/发码/撤销/转科全链路，拒绝原因全文留痕。

内置样例：

| 场景 | 患者 | 说明 |
|---|---|---|
| 正常码 | 周建国 A-0217 | 08:00–20:00 有效，扫码入区/离区 |
| 待审批 | 吴桂芳 A-0308 | 护士已登记，待护士长审批 |
| 跨病区 | 郑海涛 A-0419 | XH 的码拿到 HN 门岗 → 拒绝并提示重新申请 |
| 手机丢失 | 陈玉兰 A-0522 | 旧码已挂失撤销，扫码显示完整撤销原因 |
| 转科 | 林文斌 A-0630 | HN 码随转科即时撤销，XH 护士长重评后发新码，授权链相连 |

双入口重放：`HN-G1` 与 `HN-G2` 同时扫同一个码，只有一次入区状态变更
（可用同一码在两个浏览器/标签快速提交复现；系统内置 30 秒重放窗口）。

## 核心规则

- **角色边界**：普通护士只能处理本病区申请的登记与紧急撤销；审批发码、
  更换陪护人、封控、转科、出院、转科重评仅本病区护士长可执行；
  门岗只能核验，任何写操作返回 403。
- **限制时段配额**：每位患者在本病区的有效名额 = 待审批申请数 + 有效码数，
  不得超过配额；码撤销/换发即释放名额。
- **即时撤销**：换陪护（旧码 `replaced` 并由新码承接）、手机丢失、码泄露、
  病区封控（该病区全部码）、出院（该患者全部码，跨病区兜底）、
  转科（旧病区码全部撤销、未审结申请作废，新病区重新评估）。
- **并发**：扫码使用 `BEGIN IMMEDIATE` 事务 + `in_zone` 条件更新 + 30 秒重放窗口，
  同一码在两个入口同时扫描只允许一次入区状态变更。
- **时段边界**：窗口左闭右开，`08:00` 准入、`20:00` 拒绝。
- **隐私**：通行码只存 SHA-256 哈希（明文仅发卡时返回一次）；界面默认显示
  遮罩（`110105********2246`、`138****5678`、`周*燕`）；
  虚构证件遮罩样图存于 `data/badges/*.svg`。
- **视觉**：白灰底 `#F4F6F7/#FFFFFF` + 医院青 `#0E7C86`，门岗页 64–72px 大字。

## 目录结构

```
app/
  db.py            SQLite 连接与授权链 schema（passes.parent_pass_id / replaced_by_pass_id、
                   applications.source_application_id）
  core.py          全部业务规则：申请/审批/撤销/封控/解封/出院/转科/重评/扫码状态机
  security.py      证件/手机/姓名遮罩、通行码哈希生成、虚构证件 SVG 样图
  gate_adapter.py  模拟门禁：红绿灯 + 闸机信号，无审批能力
  server.py        标准库 HTTP 服务：门岗页/护士床位视图/记录/交接看板
  seed.py          虚构演示数据（含转科、丢码样例）
tests/             45 个 unittest（可注入时钟）
run.sh             一条本地启动命令
```

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：时段边界（07:59 / 08:00 / 19:59 / 20:00）、双门岗真实线程并发码重放、
重放窗口内连扫、跨病区扫码与护士越权、配额超额、出院撤销、封控批量撤销与解封不复活、
换陪护授权链、转科撤销+新病区重评链、门岗 HTTP 越权 403、拒绝原因全文与默认遮挡。
